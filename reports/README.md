# Executive status reports

Static HTML snapshots for meetings. Published to R2 bucket `dm-reports` (public via r2.dev,
unguessable path per report; the bucket root does not list files).

| Date | File | Public URL |
|---|---|---|
| 2026-11-18 | 2026-11-18-status.html | https://pub-880c9d1464514613b2e80087728f78da.r2.dev/migration-status-2026-11-18-e0d4faa4d106/index.html |

Numbers come from the control sheet (via the n8n broker), the Cloudflare account and `sites/`.
To retire a report, delete its object in the bucket.
